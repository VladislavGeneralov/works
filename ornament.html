ORNAMENT

Ornament is an audiovisual object generating ornamental patterns within 8×32 pixel-field. Its algorithm combines a system of strict rules with a space for pseudorandom algorithmic choices, which makes the system’s results variable and almost never repetitive.

Activation of each pixel is accompanied by the synthesis of a string sound through physical modeling techniques (Karplus–Strong algorithm).

LED matrix, arduino pro micro, daisy seed, speakers, program code
